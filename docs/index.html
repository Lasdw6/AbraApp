Set up on Windows

Requires Windows 11 or Windows 10 build 19044+, hardware virtualization, and internet access. This preview uses Ubuntu 24.04 in WSL 2. Windows ARM is not supported yet.

  1. Download and extract the Windows ZIP. Keep the extracted files together.
  2. Open PowerShell in the extracted Abra-Teleport-Windows-WSL folder and run: 
    powershell -NoProfile -ExecutionPolicy Bypass -File .\Setup-Windows.ps1
  3. Follow the Ubuntu setup prompts. If Windows asks you to restart, run the same setup command afterward.
  4. Open Abra Teleport from the desktop shortcut. Use Open Abra browser to sign in to the sites you want to send.

The app uses Chrome inside WSL. Your regular Windows Chrome and Edge profiles are not imported. Full Windows instructions

Connect your agent

In the app, choose Create command and give the command to your agent. It installs the CLI if needed and pairs the sandbox with your laptop. Then choose Find agents and select it.

Only pair an agent you trust. Your sandbox needs outbound access to Abra’s network.
